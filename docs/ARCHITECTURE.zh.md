# 架构

[English](ARCHITECTURE.md) | 简体中文

这个插件就是一个 Cordis 服务：一个类、一个被覆写的方法，以及刻意不挂在实例上的按会话状态。

## 被包住的接缝

`ctx.compaction` 是单槽位服务。实现方负责触发策略、保留与摘要，成功一次就把 surface 的一段替换成一个摘要节点。

| 部件 | 来自哪里 | 本插件拿它做什么 |
| --- | --- | --- |
| `compactIfNeeded(agent, trigger, signal)` | 父类引擎，由 `agent/pre-step` 与 `agent/request-error` 调起 | 先门控，再委派 |
| `compactNow(agent, signal, commandId)` | 父类引擎，由 `/compact` 命令调起 | 先委派，再重新武装 |
| `session/event` | harness | 数工具轮次 |

## 覆写内容

- 门控读取该会话的跟踪器，把当前工具轮次数与上次成功压缩时记录的那个值比较。
- 拒绝发生在调用父类引擎**之前**，所以一次徒劳的摘要永远不会被花掉。
- 拒绝还会**锁定**。没有锁定的话，间隔一变大闸门就会重新打开，那只是让循环变慢，而不是让它停下。
- 手动压缩从不被拒绝，并且会清掉锁定，因为一个人主动要求压缩一次，本身就是新信息。

## 状态放在哪里

按会话的状态放在模块级 WeakMap 里、以 session 为键，而解析后的策略是一个公开自有字段。

- 域曾经把这个插件的 `ctx.compaction` 对象交出来，却不带本类的私有品牌，于是私有字段读取在压缩路径里抛了错。
- 宿主会捕获从那条路径抛出的错误并继续该轮，所以这个失败是静默的：它把自动压缩关掉了，却没有报告任何东西。
- 以 session 为键的模块级映射彻底去掉了对实例身份的依赖，这也正是父包给自己的平衡缓存用的形态。

## 刻意不放的东西

- 不做摘要、保留或 surface 手术：那些是父类引擎的，重复实现等于要多维护一份可能出错的东西。
- 不访问网络、不访问凭证：本插件只测量 harness 已经测过的量。
- 没有客户端那一半：它新增的每个面都在宿主侧，所以它不发布任何浏览器代码。
